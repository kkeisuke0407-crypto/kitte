# マイクロコピー一覧とブラッシュアップ案（2026-10-14）

対象：ボタンの上の一言（＼〜／）、ボタンの文字、カードの小見出し、チップ、締めの問いかけ。
ボタンの文字は「ASPリンクを入れたあとに出る文字」です。いまの公開サイトでは、仮リンクの間だけ「〜の詳細を見る」などに置き換えて表示しています。

案は、公式サイトで確認済みの事実だけを使っています（最短翌日・24時間受付・0円・汚れやバラもOK・その場で現金・東証上場・出張／店頭／宅配・1点から相談）。

---

## 1. いまの問題点（全体）

1. **ウリエルの一言が「手数料・キャンセル料0円」ばかり**
   トップだけで5回出てきます（実績の下・組み合わせ・ランキング1位の上と下・診断の下）。何度も同じ言葉が続くと読み飛ばされます。置き場所ごとに、直前に読んだ内容に合う一言へ変えたほうが効きます。
2. **まとめカードで、ウリエルが見劣りしている**
   カードが横に2枚並ぶ所で、ウリエルは「24時間受付」、バイセルは「24時間365日受付」です。並べるとウリエルのほうが弱く見えます。
3. **「0円」と「無料」が混ざっている**
   ウリエルは「0円」、バイセルは「査定無料」「〜など無料」です。どちらも正しい表現ですが、そろえたほうが比べやすくなります。
4. **ボタンの文字が長い**
   「ウリエルの公式サイトで無料査定を申し込む」は、スマホでは3行近くになります。
5. **まとめ見出しと、その下のカードで「まずは」が重なっている**
   見出しが「まずはウリエルで査定」、カードが「まずはここ／1位 ウリエル」です。
6. **4〜6位のボタンの注記が分かりにくい**
   「（外部サイト・広告リンクではありません）」は、「外部サイトではない」とも読めてしまいます。
