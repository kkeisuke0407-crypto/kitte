## 3. 訴求の傾向

| 訴求の型 | 使っている会社 | 例 |
|---|---|---|
| **金額・倍率** | バイセル・大吉・日晃堂・ウリエル | 買取額5倍／7倍、高額買取、買取値限界に挑戦、どこよりも高く、まさかこんな値段に |
| **どんな切手でもOK** | バイセル・大吉・ウリエル | どんな切手でも、普通切手・はがきも、バラ1枚から、シート・バラ、中国切手・外国切手も |
| **価値が分からない不安** | 日晃堂・ウリエル | この切手は売れるの？、価値があるかわからない切手も、切手売るならどこがいい？、その切手、安く売らないで |
| **整理不要** | ウリエル | 整理せずそのままで、品目ごとに分ける必要はありません、タンスの中身ごと |
| **信頼・実績** | バイセル・大吉・ウリエル | CM放映中、査定44,700点超、信頼の全国展開、切手を見続けた査定士 |
| **地域名** | バイセル・大吉・日晃堂 | 【中野市】、府中で、丹波市で（地域ごとに見出しを変えている） |
| **費用0円** | 大吉・福ちゃん | 買取手数料¥0、出張料¥0 |

### 分かったこと
1. **見出しの主役は「高く売れる」**：大手は「5倍」「高額」「どこよりも」で金額を押し出しています。キャンペーンの倍率は各社の自社施策なので、比較サイトはまねできません。
2. **「価値が分からない」に寄り添う型は、まだ少ない**：使っているのは日晃堂の「この切手は売れるの？」と、ウリエルの「切手売るならどこがいい？」くらいです。
3. **「実家」「父の切手アルバム」「アルバムのまま」を見出しにした広告は見当たりません**：ウリエルの「遺品整理」「タンスの中身ごと」が近いだけです。このサイトの導入（実家で父の切手アルバムが出てきた）と同じ場面を言う広告は、ありませんでした。
4. **「断っても0円」「キャンセル無料」を見出しにした切手広告はありません**：説明文に「手数料¥0」がある程度です。
5. **「最短翌日」「汚れ・破れもOK」を使う切手広告もありません**。
6. **比較サイトの切手広告は見つかりませんでした**：調べたランキング比較サイトは、この90日に切手の広告を出していません。ただし、Google検索の実際の画面は見られていないので、「比較型の広告がない」とまでは言えません。

### 広告を出す前に確認すること
- **会社名を入れた広告（「ウリエル 切手」など）**：会社名のキーワードに入札してよいか、広告文に会社名を入れてよいかは、ASPの条件で決まります。まだ確認できていません。
- **広告とページの言葉をそろえる**：広告で「実家の切手アルバム」と言うなら、ページの最初の画面にも同じ場面を出すと、離脱が減ります。いまの導入会話は、この場面と合っています。
