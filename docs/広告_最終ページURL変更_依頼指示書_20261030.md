## 2. 変えないもの

- 上の表にない広告グループ（CP① 王道、CP② のほかのグループ、CP④ 競合）の最終ページURL。`https://kitte.navolio.net/` のまま。
- 見出し・説明文・見出しの固定・表示パス（パス1「切手買取」とパス2）。
- サイトリンク・コールアウト・構造化スニペットなどのアセット。
- 最終ページURLのサフィックス（計測用の `utm_source=google&...`）。キャンペーンの設定に入っているので、そのまま新しいURLにも付く。
- 入札戦略・予算・地域・ステータス・キーワード。

## 3. 進め方

1. 変更前に、対象18グループのRSAの最終ページURLを控える（戻せるように）。
2. 管理画面またはGoogle Ads Editorで、RSAの最終ページURLだけを書き換える。
   - Ads Editorを使う場合は、1グループずつ「最終ページURL」の欄を編集して送信する。CSVで読み込むなら、列名は英語（`Campaign` / `Ad Group` / `Final URL` など）にする（`hozon/manual/A8_GoogleAdsEditor入稿CSV規約.md`）。読み込み後に「追加」ではなく「編集」になっていることを確認する。広告が新しく増えた場合は、古い広告が二重に残らないようにする。
3. 送信後、最終ページURLを変えたRSAは再審査になる。

## 4. 確認

- 18グループのRSAの最終ページURLが、表のとおりになっている。
- 表にない広告グループのURLが変わっていない。
- 審査の状態（審査中・承認済み・不承認）。不承認や「制限付き」があれば理由を控える。
- 新しいURLを広告プレビューなどで開き、ページが表示される（全ページ公開済み）。

## 5. 完了報告に入れること

1. 変更した広告グループ数・RSA数（18グループ）
2. 変更前と変更後の最終ページURLの一覧
3. 審査の状態（不承認・制限付きがあれば理由）
4. 管理画面の名前が表と違って変更しなかったグループがあれば、その名前
